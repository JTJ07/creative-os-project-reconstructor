# Testy regresji

Testy są zanonimizowanymi specyfikacjami zachowania. Nie zawierają pełnych prywatnych rozmów ani załączników.

## Sposób użycia

Po zmianie `PROMPT_STARTOWY.md` uruchom prompt na materiale odpowiadającym każdemu scenariuszowi i sprawdź kryteria `PASS`.

Zmiana nie powinna zostać przyjęta, gdy:

- naprawia nowy przypadek, ale łamie wcześniejsze kryterium;
- rozszerza raport bez konkretnej potrzeby;
- przenosi pracę analityczną z AI na użytkownika;
- zmienia Creative OS bez jawnej zgody.

## Globalne kryteria

- analiza dotyczy projektu, nie samej rozmowy;
- komponenty nie są automatycznie nowymi projektami;
- artefakt nie jest dowodem działania;
- jeden następny krok jest pierwszym brakującym warunkiem;
- nowy projekt pozostaje `PROPOSED`;
- handoff nie zmienia się od samej analizy;
- `SOURCE OF TRUTH REQUIRED` prowadzi do pokazania gotowego draftu;
- repo pozostaje niezmienione w trybie `READ_ONLY`;
- zwykły raport pozostaje w zakresie `LITE`.
