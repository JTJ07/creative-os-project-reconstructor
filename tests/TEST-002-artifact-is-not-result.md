# TEST-002 — Artefakt nie jest działającym rezultatem

## Materiał

Projekt ma rozbudowaną dokumentację, prompty, pseudokod, checklisty i demonstracyjne skrypty, ale brak logów rzeczywistego użycia.

## Ryzyko regresji

Raport stwierdza, że system działa lub jest gotowy do wdrożenia.

## PASS

- dokumenty i kod są oznaczone jako `EXISTING ARTIFACT` albo najwyżej `EXECUTABLE MECHANISM`;
- brak `OBSERVED WORKING RESULT`, gdy nie ma zapisu użycia;
- brak `VALIDATED RESULT`, gdy nie ma walidacji;
- deklaracje dokumentacji są oddzielone od implementacji.
